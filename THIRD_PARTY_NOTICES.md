# Third-party artwork

The 55 illustrations under `dist/assets/` were retrieved from [Bioicons](https://github.com/duerrsimon/bioicons) on 2026-10-16. The original 32 illustrations use CC0. The 23 course additions use CC0, CC BY 3.0 or CC BY 4.0 as recorded per item; they were retrieved at revision `d29e766ea7580b8063c4f47b29e872db40a4d979`. Each file's source URL, author and license URL are preserved in `dist/assets/catalog.json`. Upstream files are retained unchanged on disk; the editor makes a sanitized, static vector representation at runtime. `normalized.json` contains that same technical adaptation for CLI export: class styles are expanded, unsupported active content removed and internal IDs rewritten.

CC BY 3.0: https://creativecommons.org/licenses/by/3.0/
CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

CC BY artwork requires author credit, a source/license link and identification of modifications. The application displays attribution in the properties panel and exports a per-figure list; retain it in your publication credits. Artwork licenses are separate from the application MIT license. Attribution is not endorsement.

Course additions by author: Ewa-Oz, James-Lloyd, Gina-Vong, B--Gideon-Bergheim and umasstr (CC0); Servier (CC BY 3.0 for these Bioicons files); DBCLS and Hugo-Wioland (CC BY 4.0). The catalog is authoritative for the mapping of individual files to authors and licenses.

CC0 public-domain dedication: https://creativecommons.org/publicdomain/zero/1.0/
Legal code: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The Bioicons application code is not bundled. Only the selected artwork and its factual catalog metadata are distributed. All other Bioicons assets are outside this distribution and may use different licenses.

No draw.io, Inkscape or OpenBioFigure code is bundled. The application provides format interoperability and links to these independent upstream projects.
